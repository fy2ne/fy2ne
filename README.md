**[VACT](https://vact.fy2ne.me)** → Vector Agent Context Transport. High-frequency GPU screen perception pipeline and IPC transport protocol for desktop autonomous agents. Uses Direct3D 11 compute shaders and connected component labeling to replace screenshot polling with sub-5ms vector DAG deltas at 60 FPS (99.8% token drop).

**[Weavetab](https://github.com/Weavetab)** → open-source Layer 0 interface for AI browser automation built directly on Chrome DevTools Protocol. Ships as a bi-directional Chrome extension + MCP server. Pure local CDP socket control, zero WebDriver overhead. (MCP, SDK, Skills, Plugins, Studio)

**[Essential-Devs](https://github.com/Essential-Devs)** → development collective building tools and infrastructure at the edge of undocumented protocols and developer runtimes as **private** repos

**[fy2ne.me](https://fy2ne.me)** → personal website, architecture breakdowns, and research logs.
